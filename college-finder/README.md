# PathwayU - AI-Powered College Recommendation System

An intelligent web application that helps students find their perfect college match by answering 15 personalized questions. The system uses a weighted matching algorithm and AI-generated summaries to provide tailored recommendations.

## Features

- 15 weighted questions covering all major college decision factors
- Conversational UI with progress tracking
- AI-powered personalized summaries (using Claude API)
- Top 5 college recommendations with match scores
- Honorable mentions for additional options
- Direct links to university websites and scholarship pages
- Session persistence - save and resume later
- Responsive design for mobile and desktop

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- Claude API Key from [Anthropic Console](https://console.anthropic.com/)

### Installation

1. **Navigate to the project directory:**
   ```bash
   cd college-finder
   ```

2. **Dependencies are already installed**, but if needed:
   ```bash
   npm install
   ```

3. **Add your Claude API key:**
   - Open the `.env` file
   - Replace `your_claude_api_key_here` with your actual API key:
   ```
   CLAUDE_API_KEY=sk-ant-api03-xxxxx
   ```

### Running the Application

1. **Start the server:**
   ```bash
   npm start
   ```

2. **Open your browser and visit:**
   ```
   http://localhost:3000
   ```

3. **Start the quiz** and answer the 15 questions to get your personalized college recommendations!

## How It Works

### 1. Question Weighting
Questions are weighted by importance based on research about student priorities:
- Budget (15%)
- Financial Aid (12%)
- Location (10%)
- Major (10%)
- Post-Graduation Outcomes (8%)
- ...and 10 more factors

### 2. Matching Algorithm
For each college, the system:
1. Scores the college on each factor (0-100)
2. Multiplies each score by its weight
3. Sums all weighted scores for a final match percentage
4. Ranks all colleges by match score

### 3. AI Summaries
The top 5 colleges get personalized summaries generated by Claude AI, explaining why each college is a great fit based on your specific preferences.

## Database

The system includes 30 sample colleges representing:
- 4-year universities and community colleges
- All US regions (Northeast, Southeast, Midwest, Southwest, West Coast)
- Various sizes (small, medium, large)
- Different price ranges ($8,000 - $85,000 annually)

### Adding More Colleges

To add more colleges to the database:

1. Edit `database/seed-data/colleges.csv` and add rows following the existing format
2. Re-run the import script:
   ```bash
   npm run import-data
   ```

Or use the College Scorecard API to import thousands of real colleges (see plan document for details).

## API Endpoints

### Sessions
- `POST /api/session/start` - Create a new session
- `GET /api/session/:sessionId` - Get session data
- `PUT /api/session/:sessionId` - Update session

### Questions
- `GET /api/questions` - Get all 15 questions
- `POST /api/questions/answer` - Submit an answer

### Matching
- `POST /api/match` - Generate recommendations
- `GET /api/results/:sessionId` - Get saved results

## Customization

### Changing Question Weights
Edit `services/matching-engine.js` and modify the `WEIGHTS` object.

### Adding/Modifying Questions
Edit `routes/conversation.js` and modify the `QUESTIONS` array.

### Changing AI Model
Edit `services/ai-service.js` to use a different model or provider (e.g., OpenAI GPT-4).

## Troubleshooting

**Server won't start:**
- Check that port 3000 is not already in use
- Verify all dependencies are installed (`npm install`)

**AI summaries not generating:**
- Verify your Claude API key is correctly set in `.env`
- Check your API key has sufficient credits
- Look at server console for error messages

**Database errors:**
- Re-run database initialization: `npm run init-db`
- Re-import data: `npm run import-data`

**Frontend not loading:**
- Clear browser cache
- Check browser console for JavaScript errors
- Verify server is running on port 3000
